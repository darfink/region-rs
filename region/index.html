Cross-platform virtual memory API.

This crate provides a cross-platform Rust API for allocating, querying, locking, and manipulating virtual memory. It is a thin abstraction over platform-specific APIs (e.g., VirtualAlloc, VirtualQuery, VirtualLock on Windows; mmap, mprotect, mlock on Unix-like systems). Not all OS-specific quirks are abstracted away: for instance, some OSs enforce that executable pages are readable, while others prevent pages from becoming executable at all (e.g., DEP or W^X).

Operations work on memory pages aligned to the operating system’s page size. Because some platforms require page-aligned arguments for these system calls and others do not, inputs are rounded to page boundaries automatically where applicable.

Note: a region is a collection of one or more pages lying consecutively in memory with the same properties.

§Concurrency

Virtual memory mappings can change at any time unless all other threads in the process are stopped. Any queried Region therefore represents a point-in-time snapshot of the process’s address space.

§Installation

Add region to your Cargo.toml:

[dependencies]
region = "4"

§Features

The std feature is enabled by default. Disable default features to use this crate as #![no_std] with alloc:

[dependencies]
region = { version = "4", default-features = false }

With std enabled, Error implements std::error::Error and converts into std::io::Error.

§Examples

  • Cross-platform equivalents.

    let data = [0xDE, 0xAD, 0xBE, 0xEF];

// Page size
let pz = region::page::size();
let pc = region::page::ceil(data.as_ptr());
let pf = region::page::floor(data.as_ptr());

// VirtualQuery | '/proc/self/maps'
let q  = region::query(data.as_ptr())?;
let qr = region::query_range(data.as_ptr(), data.len())?;

// VirtualAlloc | mmap
let alloc = region::alloc(100, Protection::READ_WRITE)?;

// VirtualProtect | mprotect
region::protect(data.as_ptr(), data.len(), Protection::READ_WRITE_EXECUTE)?;

// ... you can also temporarily change one or more pages' protection
let handle = region::protect_with_handle(data.as_ptr(), data.len(), Protection::READ_WRITE_EXECUTE)?;

// VirtualLock | mlock
let guard = region::lock(data.as_ptr(), data.len())?;
